Section 1 // Threat Surface

Industrial Fraud Context

The Evolution of Synthetic Social Coercion

  • 3-Second Audio Harvests: Public audio snippets from micro-social accounts are synthesized instantly into full-fidelity vocoders, spoofing relatives' exact voice textures.
  • High-Stress Family Exploits: Scammers simulate crises (accidents, detention, kidnapping) to demand immediate untraceable wire transfers under psychological duress.
  • Domain homoglyphing: Cyrillic text substitutes (e.g., using `I` for `l` in URLs) deceive standard users into exposing login credentials.
Critical Security Definiton:
Traditional network filters cannot defend against vocal deepfakes once the scammer succeeds in executing a voice spoof. The defense barrier must occur at the human cognitive layer using protocol checks and safe words.

Continuous Security Without Active Network Feeds

Section 6 // Verbal Gate Protocols

Combating Real-time Voice Spoofing

Oral Safe Word Passcodes Mapped Securely inside Room Database

Software filters cannot guarantee real-time verbal safety. The most robust security gate is the use of out-of-band oral challenge keys:

  • Custom Questions: Setup intimate household questions (e.g., *"What was the name of the dog we rescued behind the old barn?"*).
  • Stress-Support Checklist: A logical verification card handles the mental tracking of checks during highly emotional crisis state phone calls.
  • Enforced Sandbox Isolation: Crucial credentials reside locally within SQLite storage, never uploaded to outer networks.
@Entity(tableName = "family_codes")
data class FamilyCodeEntity(
    @PrimaryKey(autoGenerate = true) 
    val id: Long = 0,
    val memberName: String,
    val challengeQuestion: String,
    val securityAnswer: String,
    val dateSet: Long = System.currentTimeMillis(),
    val isVerified: Boolean = false
)

Section 10 // Technical Stack

Under-the-Hood Stack Anatomy

Modern, Type-Safe Android Build Blueprint

  • Platform Core: Kotlin-powered Jetpack Compose ensuring an edge-to-edge layout, responsive Window Insets, custom status-bar paddings, and system navigation bar integration.
  • Reactive Architecture: Pure MVVM model using `MutableStateFlow` and declarative Kotlin Coroutines. State layers update automatically using the standard SQLite `combine` triggers.

  • Reliable Networking: Core OkHttpClient engine equipped with targeted connection timeout parameters to ensure safe, fail-fast client operations.

Section 11 // System Storage Core

The Room SQLite Datastore

Offline-First Schema Mappings for Complete Security Isolation

1. Table: `threat_scans`

Matches individual scanned records: `id`, `date`, `inputSource` (text, url, link, transcript), `inputContent`, `threatLevel`, `confidenceScore`, `analysisReport`, `indicatorsFound` (comma-separated list).

2. Table: `family_codes`

Oral safe verification data: `id`, `memberName`, `challengeQuestion`, `securityAnswer`, `dateSet`, `isVerified` status toggle.

3. Table: `quiz_scores`

Education logs and progress metrics: `id`, `quizTitle`, `score`, `totalQuestions`, `dateCompleted`, `category` string.

4. Table: `scam_reports`

Telemetry tracking: `id`, `title`, `scamType`, `sourcePlatform`, `suspectedSender`, `description`, `impactLevel`, `reporterEmail`, `dateSubmitted`, `status`, `statusDetails` for dynamic updates.
